# Static Passport detail previews

Mike chose the real Passport redesign as the website's visual reference on 2026-10-13. The four homepage detail cards are static images captured from `git-lucky/huntstack-game`, `origin/redesign/player` at `c0c453f0` (PR #186, unshipped at capture time).

The screenshots use the actual game components at a 390×844 viewport and 2× device scale, giving 780×1688 images. Photo, video, trivia and choice challenges contain the website's existing example titles, missions, points and pictures. They run in a separate local Supabase fixture; no production game was joined.

Files: `public/img/practice/detail-{photo,video,trivia,choice}-passport.webp`. These are lossless WebP conversions, checked against the source PNGs pixel for pixel. They preserve the real picture area, type, spacing, colors, answer controls and bottom action. Mike’s website-only change replaces the points inside the picture ring with the kind icon on a semi-opaque dark disc. The overlay uses the original photo crop to cover the old number, then draws the disc, dashed ring and icon. Its position and size come from the real screen: x 277.5, y 206.5, diameter 104.5 within the 390×844 capture. The phone list still shows the points. Lazy loading avoids downloading offscreen cards until needed.

The four kind names remain Snap it, Film it, Answer it and Pick one. The pictured controls follow the actual detail screens: photo/video use their named blue action, trivia uses a bottom answer field with an arrow, and choice uses the lettered options plus “Submit answer”. All are pixels, with descriptive alt text, not working controls. The phone is the list view of the same four challenges, driven from the same `detailCards` data in photo/video/trivia/choice order. Rows and cards are native buttons. A small script highlights the counterpart for 2.2 seconds, with no scrolling, navigation or focus transfer. Enter and Space activate them; reduced motion gets a steady rounded gold ring. Without JavaScript they leave the static preview untouched. The phone and all four full cards fit together on desktop at 1440×900 and 1280×800; the cards stay stacked on phones. The cards and highlights use the site’s 28px radius.

When the game's design or these examples change, recapture these screens from the new revision rather than approximating them in CSS. Keep the detail pictures non-interactive: no game dialogs, photo picker, answers, stamps or reset.
